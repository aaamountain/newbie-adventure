# STM32 LED控制系统

基于正点原子战舰STM32开发板的LED控制系统，实现通过按键和串口双向控制LED灯的工作模式。

## 功能特性

### 1. 按键控制功能
- **KEY0 (PE4)**: 切换到模式0 (LED0亮，LED1灭)
- **KEY2 (PE2)**: 切换到模式1 (LED1亮，LED0灭)  
- **KEY1 (PE3)**: 暂停/继续状态切换

### 2. 串口通信功能
- **波特率**: 115200
- **指令**: "P" - 实现暂停/继续控制
- **状态上报**: 实时显示当前LED状态

### 3. LED指示
- **LED0 (PB5)**: 模式0时点亮
- **LED1 (PE5)**: 模式1时点亮

## 硬件连接

| 功能 | 引脚 | 说明 |
|------|------|------|
| LED0 | PB5 | 低电平点亮 |
| LED1 | PE5 | 低电平点亮 |
| KEY0 | PE4 | 上拉输入，按下为低电平 |
| KEY1 | PE3 | 上拉输入，按下为低电平 |
| KEY2 | PE2 | 上拉输入，按下为低电平 |
| USART1_TX | PA9 | 串口发送 |
| USART1_RX | PA10 | 串口接收 |

## 工作逻辑

### 正常工作模式
1. **模式0**: LED0点亮，LED1熄灭
2. **模式1**: LED1点亮，LED0熄灭
3. 按KEY0切换到模式0，按KEY2切换到模式1

### 暂停功能
1. 按KEY1或发送串口指令"P"可切换暂停/继续状态
2. 暂停状态下，KEY0和KEY2按键无效
3. 继续时恢复到暂停前的工作模式

### 串口状态上报
系统实时通过串口上报以下状态：
- "LED0亮，LED1灭"
- "LED0灭，LED1亮"  
- "暂停"

## 编译说明

需要安装ARM GCC工具链：
```bash
# 编译项目
make

# 清理编译文件
make clean
```

## 使用说明

1. 将程序烧录到STM32开发板
2. 连接串口调试工具（115200波特率）
3. 通过按键或串口指令控制LED状态
4. 观察串口输出的状态信息

## 串口指令

- 发送 "P" + 回车：切换暂停/继续状态

## 状态指示

- 系统运行时LED会根据当前模式显示
- 串口会实时输出当前状态
- 每5秒输出一次系统信息

## 技术特点

- 按键防抖处理
- 串口中断接收
- 实时状态监控和上报
